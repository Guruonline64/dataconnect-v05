# Data Connect V08.6

Android-to-backend integration foundation:
- Central API client
- Login/register API calls
- Dashboard/data plans/wallet/transactions/notifications/share/withdrawal service methods
- Authorization bearer header support
- Internet permission

Before using the app against a real backend, replace `BASE_URL` in `DataConnectApiClient.kt` with the company's HTTPS PHP API URL.

No VTU credentials are included in the Android project.

Important: the current repository may still contain prototype UI screens. This version establishes the real API communication layer; screen-by-screen UI binding is the next integration task.
