# Start Here — Data Connect V10

Open this folder in Android Studio:

`DataConnect_V07_2_AndroidStudio`

## Build
- Allow Android Studio/Gradle to sync.
- Build > Make Project.
- Run on an Android emulator or physical device.

## Backend connection
Inside the app:

Account → Backend Connection

Enter the HTTPS base URL of the deployed PHP backend.

Do not put API provider secrets in the app.
