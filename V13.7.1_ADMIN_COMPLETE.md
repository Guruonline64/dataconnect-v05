# Data Connect V13.7.1 — Admin Management

Added:
- Admin-only User Management module
- User search/filter
- Current role display
- Admin role-assignment workflow
- Customer, Marketer, Staff/SIC and Dispenser role choices
- Confirmation before role change
- Admin access guard
- Suspend/activate action helpers
- V13.7.1 styling

Security note:
The UI is not the security boundary. Production Laravel endpoints must verify an authenticated admin before every role, suspension, activation, transaction or user-management mutation.
