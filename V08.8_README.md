# Data Connect V08.8

V08.8 establishes the application navigation contract and presentation model for the customer and staff experiences.

Customer destinations:
Dashboard, Data Center, Airtime, Wallet, Transactions, Shares, Withdrawal, Account, Notifications, Marketer, SIC Staff Chat, Customer Care.

Staff destinations:
Staff Dashboard, Airtime Requests, Withdrawal Requests, Marketers, SIC Staff Chat, Account.

Brand:
Data connect — Smart way to buy data
White/blue presentation.

Financial actions remain backend-controlled. The Android client only requests an operation and should refresh from the server afterward.

This is the navigation/integration layer; visual UI may still need to be mapped to the project's existing Activity/Fragment/Compose implementation.
