# Data Connect V08.7

This release adds the Android screen-integration layer:
- Login state and bearer-token session
- Dashboard state
- Wallet/share/notification/transaction loading facade
- Data-plan loading facade
- Consistent loading/error state

QA sequence:
1. Build the APK with GitHub Actions.
2. Install it on an Android phone.
3. Set the API base URL to the company's test HTTPS server.
4. Register/login.
5. Confirm dashboard loads wallet balance and active shares.
6. Confirm Data Center loads real plans.
7. Confirm wallet, transactions, shares and withdrawal history load.
8. Test staff functions using a staff account.

The UI must never treat a local value as proof of a successful financial transaction; it should refresh from the server after each operation.
