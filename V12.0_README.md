# Data Connect V12.0 — Wallet & Transaction Engine

- Live wallet balance refresh and transaction history from MySQL.
- Withdrawal requests reserve funds immediately to prevent double spending.
- Rejected withdrawals release the reservation with a refund ledger entry.
- Approved withdrawals consume the existing reservation and do not debit twice.
- Share returns use supported wallet ledger types.
- Failed data orders automatically attempt a wallet refund.

Run `backend/database/migration_v12.sql` once on an existing V11 database.
