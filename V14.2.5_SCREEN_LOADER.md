# DataConnect V14.2.5 — Premium Screen Loader

Added a polished fintech-style screen loader for startup and screen transitions. It uses the Data Connect brand, a subtle backdrop blur, animated spinner, progress bar and context-aware loading text. It adapts to dark mode and respects reduced-motion preferences.

The loader is an original Data Connect implementation inspired by modern mobile-finance UX; it does not copy OPay assets or branding.

Also corrected biometric behavior so a normal password login does not silently enable fingerprint login; enabling remains an explicit Account > Security action.
