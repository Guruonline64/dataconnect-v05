# Data Connect V13.8.1 Backend API Completion

Added backend integration contract for operational roles.

Required endpoints:

Admin:
GET /api/admin/users
POST /api/admin/assign-role
POST /api/admin/remove-role
POST /api/admin/suspend-user
POST /api/admin/activate-user

Marketer:
GET /api/marketer/dashboard
GET /api/marketer/customers
GET /api/marketer/earnings

Staff/SIC:
GET /api/staff/dashboard
GET /api/staff/requests
POST /api/staff/update-status

Dispenser:
GET /api/dispenser/tasks
POST /api/dispenser/process

Security:
Every endpoint must verify the authenticated user's role on the server.
