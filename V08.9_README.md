# Data Connect V08.9

This release adds a concrete white/blue Android dashboard shell so the APK has a visible Data Connect interface instead of an empty screen.

Visible:
- Data connect branding and slogan
- Wallet balance card
- Active shares count
- Unread notification count
- Data Center, Airtime, Wallet, Shares, Withdrawal, Account and Customer Care actions

The dashboard refreshes its summary through the V08 API controller. Service buttons are navigation placeholders for the next screen-wiring pass; they do not fake successful transactions.

The company backend URL still needs to be configured before live data can be retrieved.
