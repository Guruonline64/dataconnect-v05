# Data Connect — Frontend Version 03 Complete

A complete mobile-first frontend prototype for **Data Connect — Smart Way to Buy Data**.

## Included modules
- Splash / onboarding
- Login / sign up
- Home dashboard
- Data Center: network → plan → recipient → summary → confirm → pending → success/failure
- Airtime purchase flow
- Wallet / funding UI
- Transactions
- Shares / proposed shareholder packages
- Withdrawal
- Marketer profile/application UI
- Notifications
- Customer Care / SIC chat UI
- Account / security settings
- PWA manifest

## Important
This is a frontend prototype. Wallet balances, authentication, withdrawals, shareholder calculations, API vending, payments, notifications and chat are not connected to a production backend yet.

The shareholder figures are client-provided proposed packages and should be legally/business validated before being used as live investment claims.

## Run
Open `index.html` in a browser. For best PWA behavior, serve the folder through a local HTTP server.

## Next production phase
