# Data Connect V13.6 — Forgot Password

Login now has a Forgot password action.

Production flow:
1. User enters registered email/phone.
2. App POSTs to `/auth/forgot-password`.
3. Backend sends a reset code.
4. User enters the code.
5. App POSTs to `/auth/reset-password` with the new password.

Offline APK demo:
- Generates a temporary demo code locally so the UI flow can be tested.
- This is NOT suitable for production authentication.

Production security requirements:
- Reset codes must be generated and verified server-side.
- Store passwords only as strong password hashes.
- Codes should expire and be single-use.
- Never return reset codes in API responses in production.
