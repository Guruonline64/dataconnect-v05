# V08.2 Provider setup

This release adds a server-side provider adapter boundary.

The Android client never receives provider credentials.

Before production VTU.ng activation, the company must provide:
1. Production PHP/MySQL hosting with HTTPS.
2. The exact VTU.ng API documentation/endpoint and required request fields.
3. Production VTU credentials.

Set provider secrets as server environment variables:
- VTU_BASE_URL
- VTU_TOKEN

Do not commit `.env` or credentials to GitHub.

The current adapter intentionally refuses to guess an endpoint or payload. This prevents sending money/data requests to an incorrect API.
