# Data Connect V11.0

V11 continues directly from V10.0 and focuses on making the Android app genuinely backend-ready.

## Included
- HTTPS PHP API connection settings
- Backend health-check button
- API URL normalization (`https://host` or `https://host/api`)
- Login and registration wired to the PHP API
- Registration immediately authenticates the new account
- JWT token compatibility and logout cleanup
- 15-second API timeout and clearer connection errors
- Data Center purchase flow wired to `/api/purchase-data.php` when backend mode is enabled
- Live wallet refresh after a successful order request
- Fixed the V10 JavaScript packaging newline bug
- Fixed the marketer API PHP syntax error
- Version bumped to 1.1.0 / versionCode 110

## Backend setup
1. Deploy `backend/` to an HTTPS PHP server.
2. Create the MySQL database using `backend/database/schema.sql`.
3. Configure `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, and a strong `JWT_SECRET` in the server environment.
4. Open the app → Account → Backend Connection.
5. Enter the HTTPS host, for example `https://your-domain.com`.
6. Tap **Test connection**.
7. Register a test user and log in.

## Important
The current backend creates data orders and deducts wallet balance, but provider delivery is still a separate processing stage. Do not connect real customer money or a VTU provider until the business rules, provider credentials, refund handling, transaction reconciliation, and server security have been tested.
