# Data Connect V10.0 — Android + Backend-Ready Frontend

This version continues the uploaded V09.1 Android Studio project rather than restarting it.

## V10.0 improvements
- Preserves the existing WebView/PWA customer interface.
- Fixes the frontend API `base()` compatibility issue.
- Makes API authentication token handling consistent.
- Adds API request timeout and clearer connection errors.
- Clears stale authentication after HTTP 401 responses.
- Fixes the Backend Connection screen so it actually saves the configured API URL.
- Adds the Backend Connection screen to the app router.
- Improves Android WebView cleanup and error handling.
- Keeps HTTPS-only application networking.
- Updates app version to 1.0.0 / versionCode 100.
