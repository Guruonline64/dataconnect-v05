# Data Connect V13.6.1 — Backend Integration Fix

## Fixed
- Android forgot-password calls now use `/api/auth/forgot-password`.
- Android reset-password calls now use `/api/auth/reset-password`.
- Laravel API route scaffold added when missing.
- Secure reset design uses Laravel's password broker rather than returning reset codes.
- Production reset delivery requires configured mail/SMS provider.

## Production configuration still required
- Company API domain in the Android backend URL configuration.
- Laravel APP_URL.
- Database credentials.
- Mail/SMS credentials for password reset delivery.
- VTU provider base URL and credentials.

## Security
- Never put database credentials or VTU secrets in the APK.
- Password reset tokens/codes must be short-lived and single-use.
- Do not return reset tokens/codes from production APIs.
- Backend must enforce Marketer, Staff/SIC, Dispenser and Admin permissions.
