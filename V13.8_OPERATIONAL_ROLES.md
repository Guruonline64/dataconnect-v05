# Data Connect V13.8 — Operational Roles

Added operational role dashboard structure for:
- Marketer
- Staff/SIC
- Dispenser

Customer remains outside privileged role dashboards.

Role-specific sections:
Marketer: Assigned Customers, Referral Activity, Marketing Status, Earnings.
Staff/SIC: Pending Requests, Airtime/Data Requests, Processing, Completed.
Dispenser: Assigned Requests, Process Request, Completed, History.

Security:
The backend must authorize every operational request by authenticated role. UI visibility is not a security boundary.
