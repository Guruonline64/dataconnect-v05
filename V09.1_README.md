# Data Connect V09.1

This package is based on the uploaded Data Connect Android project and keeps its existing WebView-based customer UI.

V09.1 fixes the frontend API configuration mismatch and adds client methods for:
- Data plans and purchase
- Airtime requests
- Wallet, transactions, notifications
- Shares, holdings and returns
- Withdrawals
- Backend health

The visible app already contains customer pages such as login, dashboard, Data Center, Airtime, Wallet, Shares, Withdrawal, Marketer, Staff, Notifications, Customer Care and Account. V09.1 makes the API layer consistent so those pages can be wired to the server.

Important:
- The app must use the company's HTTPS API URL before live data works.
- VTU.ng credentials must remain on the PHP server.
- Do not use demo balances or demo success messages for production.
