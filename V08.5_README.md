# Data Connect V08.5

This release consolidates the customer-facing and staff-facing backend routes.

Customer routes:
- dashboard
- data plans
- airtime requests
- wallet
- transactions
- notifications
- shares/holdings/returns
- withdrawals

Staff routes:
- staff dashboard
- staff airtime queue/approval/rejection
- withdrawal queue/decisions
- marketer queue/decisions

The Android project includes a route registry so the frontend can be wired to the PHP API without embedding provider credentials.

Production deployment remains separate: company hosting/domain, HTTPS, database credentials, secure authentication/session infrastructure, rate limiting, CORS policy, backups, monitoring, and the confirmed VTU.ng API contract.
